Bonsai Gmail Tools

Bonsai Gmail Tools is a personal-use automation. It is not a public product and is not distributed to anyone. Its sole user and beneficiary is the account owner.

What the app does

The app lets the owner's own personal assistant software read and manage the owner's own Gmail mailboxes: listing inbox messages, reading message content, and saving drafts. All access is to the owner's own accounts. The app never accesses any other person's data.

Google user data accessed

The app requests this Google OAuth scope:

  • https://mail.google.com/ — full Gmail access for the owner's own mailboxes (read messages, list messages, create drafts).
