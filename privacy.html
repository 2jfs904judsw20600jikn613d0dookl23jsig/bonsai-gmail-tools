Privacy Policy — Bonsai Gmail Tools

Bonsai Gmail Tools is a personal-use automation operated by its sole user (the "Owner"). This policy describes how the app handles Google user data. It applies to the Owner's own Google accounts only; the app does not serve or collect data from any other person.

What data is accessed

With the Owner's explicit OAuth consent, the app accesses the Owner's own Gmail data through the following scope:

  • https://mail.google.com/ — read messages, list messages, and create drafts in the Owner's own mailboxes.

How data is used

Accessed data is used exclusively to carry out the Owner's own automation tasks on the Owner's own mailboxes — for example, reading unread mail or composing drafts at the Owner's direction. No data is used for advertising, profiling, machine-training on other users' data, resale, or any purpose unrelated to operating the Owner's own automation.

How data is stored

OAuth refresh tokens are stored encrypted in the Owner's local password-vault on the Owner's own computer. Message data is held only in the memory of the Owner's local automation while a task runs, and in the Owner's own conversation records, which also stay on the Owner's machine. No Google user data is stored on any third-party server.

How data is shared

Google user data is never shared with, sold to, or transferred to any third party. No human besides the Owner reads the accessed data. The app does not use Google user data to develop machine-learning or generative-AI models.

Retention and deletion

Message data exists only transiently while a task runs, except where the Owner deliberately saves a record locally. The Owner can revoke the app's access at any time from their Google Account security settings, which invalidates the stored token immediately; the app's access ends with it.

Contact

This app has no external support channel. The Owner of the app is its sole operator and user.
